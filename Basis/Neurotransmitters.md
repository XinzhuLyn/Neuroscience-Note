# 递质系统的研究

符合以下条件的分子可被考虑为**Neurotransmitter神经递质**：

  （1）该分子必须在突触前神经元内合成并储存于突触前神经元内；

    --鉴定方法：

    ｜免疫细胞化学（ immunocytochemistry )：利用特异性抗体与细胞内的特定抗原（通常是蛋白质） 结合，并通过显色或荧光标记来定位该蛋白质在细胞或组织中的位置。
    
    ｜原位杂交( in situ hybridization )：利用标记的核酸探针（DNA或RNA）与细胞内的特定mRNA序列进行碱基互补配对，从而定位该基因在组织中的转录位点（即哪些细胞正在表达该基因）。
    
    ｜放射自显影（Autoradiography）：将放射性同位素（如³H、¹⁴C、¹²⁵I）标记的配体（如药物、神经递质、代谢底物）引入组织或动物体内，然后让组织切片与感光乳胶接触，放射性衰变产生的射线会在乳胶上形成银颗粒（显影后呈现黑点），从而显示放射性标记物的分布。

（2）在突触前神经元收到刺激后，该分子必须由突触前神经元释放；

    ｜光遗传学刺激

（3）将该分子施加于实验系统中，必须能够引起突触后细胞的反应，即可以模拟突触前神经元释放的神经递质所引起的反应。
    
    ｜微量离子电泳( microiontophoresis)：通过微电极（尖端极细，通常<1微米）施加微小电流，将带电的药物分子或神经递质直接推送到单个神经元附近，以观察其对神经元放电活动的影响。

 ## 受体研究-- receptor subtype

每一种神经递质都是通过与特异性受体结合而发挥其突触后效应的。

｜没有两种神经递质可以与同一受体结合的情况

｜一种神经递质可以与不同的受体结合。能够与同一种递质结合的不同受体为**受体亚型（receptor subtype）**

```
  --目前发现3种方法最适合用于receptor subtype研究：

  1.「神经药理学分析·功能维度」：观察药物对生理/病理反应的量效与时效影响；
  2.「配体结合法·识别维度」：利用放射性、荧光标记的配体，在体外测定与其受体蛋白的结合动力学参数;
  3.「受体蛋白分子分析·结构维度」：借助免疫印迹、免疫组化直接检测受体蛋白的氨基酸序列。
```

  ## 受体研究--ACh乙酰胆碱

 ACh的受体亚型有两种，分别是：

·**Nicotine ACh receptor**  （离子型）：直接引起离子通道变化，膜去极化，动作电位产生导致肌肉收缩；

Agonist：烟碱（Nicotine)

Antagonist：箭毒（Curare）

·**Muscarine ACh receptor**（代谢型-G蛋白偶联受体）：打开K+通道，导致K+外流增加，更难generate动作电位。

Agonist：毒蕈碱(Muscarine)

Antagonist：阿托品(Atropine)

**因此，ACh可以减慢心率，Muscarine可以使心率和血压急剧下降**
